# 需求规格说明书 v0.4

> 项目：study-loop —— 课程资料管理与错题复习系统
> 角色范围：**仅学生（个人学习工具，多账号各自隔离）**
>
> **v0.4 变更**（相对 v0.3）：
> 1. **扫描版 PDF / 图片型 PPT 纳入范围**：新增逐页 OCR 兜底。
> 2. 解析统一为一条管线：**一切格式先转 PDF → 页面渲染 → 逐页取文字（原生 or OCR）**。
> 3. Office 在线预览不再是"待定"，改为必做（不转 PDF 就无法划选出题）。
> 4. 明确"预览"的定义：网页内可翻页、可选中、可搜索的阅读器，不是下载。

---

## 1. 定位

一个**个人**的课程学习工作台。核心不是"存资料"，而是让每一份资料都能**被读、被搜、被出题**，每道题都能**回到原文那一页**。

```
① 存：课件 PDF / PPT / Word
② 转：统一转成 PDF（原件保留）→ 网页里可翻页阅读
③ 取：逐页取文字；扫描页走 OCR
④ 出题：划选一句话 → 变成一道题（带页码）
⑤ 复习：客观题程序判分，主观题自评，SM-2 排期
⑥ 回看：复习时点"看原文" → 跳回那份 PDF 的第 12 页
```

**"在线预览"是什么**：不是下载到本地用 WPS 打开，也不是调用 Office 网页版，而是把文件渲染在浏览器里，支持翻页、缩放、**选中文字**、搜索并跳页。
没有这一层，"划选出题"和"复习回原文"都不成立，系统就退化成网盘。所以预览属于**核心交互**，并非可选装饰。

**本期聚焦**：文档（含扫描件）。视频作为 V3 扩展，设计已留口子（见 ADR-0006 / ADR-0008）。

## 3. 范围与分期

| 期 | 主题 | 内容 | 演示状态 |
|---|---|---|---|
| **V1** | 文档闭环 | 账号、课程/章节、上传、**统一转 PDF**、页面渲染、原生文本抽取、**逐页 OCR 兜底**、分题型题库、客观题判分、今日复习（SM-2）、基础统计 | 传一份扫描版课件 → 变成可选中可搜索的页面 → 划选出题 → 复习判分 → 跳回原页 |
| **V2** | 检索与自测 | 全文检索、页面缩略图、解析进度、组卷自测、图表统计、提醒 | 搜"红黑树"定位到第 12 页；组卷 10 题自动出分 |
| **V3** | 视频（延后） | 多来源导入、字幕/云 ASR、段落时间戳、段落出题 | 见 ADR-0006 / ADR-0008 |

**明确不做：**

| 不做 | 理由 |
|---|---|
| LLM 生成摘要 | 依赖网络与费用，与"出题—复习"主线关系弱 |
| 在线编辑原文件 | 只读场景，编辑会引入版本与协作复杂度 |
| 教师端 / 班级 / 分享 | 需求已明确为个人工具 |
| 手写公式识别 | 公式 OCR 需要专门模型，识别率不可控 |
| 视频解析 | 本期延后，非砍掉 |

### 4.4 解析管线（本版重点）

**一条管线，所有格式收敛到同一种形态：可渲染的页 + 每页的文字。**

```
上传
 └→ ① 统一转 PDF（非 PDF 才转，LibreOffice headless）
     └→ ② pdf.js 逐页渲染（前端）
         └→ ③ 逐页抽文字（PDFBox）
             └→ 文字 < 20 字符？
                  ├ 否 → text_source = NATIVE
                  └ 是 → ④ 该页转图 → 云 OCR → text_source = OCR
                          └→ ⑤ 落 doc_page（page_no, text, text_source）
```

| 编号 | 功能 | 说明 | 期 |
|---|---|---|---|
| FR-14 | 统一转 PDF | doc/docx/ppt/pptx 用 LibreOffice 转 PDF；PDF 直通；**转换产物与原件分开存** | V1 |
| FR-15 | 页面渲染 | pdf.js 按页渲染，支持翻页、跳页、缩放、缩略图 | V1 |
| FR-16 | 原生文本抽取 | PDFBox 逐页取文本；正常 PDF 秒级完成 | V1 |
| FR-17 | OCR 兜底 | 单页文本 < 20 字符 → 该页渲染为 PNG → 调云 OCR → 写入该页文字 | V1 |
| FR-18 | 来源标记 | 每页记 `text_source = NATIVE / OCR / NONE`；界面标注"本页为识别文字" | V1 |
| FR-19 | 文字面板 | 扫描页在右侧展示"本页文字"，可选中、复制、用于出题 | V1 |
| FR-20 | 页码口径 | 统一用**转换后 PDF 的页码**；DOCX 转 PDF 后页码可能与 Word 不同，界面注明"页码以预览为准" | V1 |
| FR-21 | 页面缩略图 | 生成每页缩略图（PNG，宽 200px）存 MinIO，用于快速跳转 | V2 |
| FR-22 | 全文检索 | MySQL `FULLTEXT` + `ngram`，命中跳页并高亮 | V2 |
| FR-23 | 选中出题 | 原生页直接划选；扫描页在文字面板选中 → 出题带 `material_id + page_no + quote` | V1 |
| FR-24 | 解析状态 | `PENDING / CONVERTING / EXTRACTING / OCR / SUCCESS / PARTIAL / FAILED` | V1 |
| FR-25 | 重试与重解析 | 转换失败、OCR 失败可重试；换 OCR 配置后可整篇重解析 | V2 |

**为什么扫描页不做"透明文字层"**：把 OCR 文字按坐标叠在图上，需要逐字对齐，一旦错位，选中会串行、体验比没有更差。改为**右侧文字面板**：用户在面板里选中、出题、复制，图的阅读体验不受影响。牺牲一点"所见即所选"，换来稳定。

## 5. 业务规则

| 编号 | 规则 |
|---|---|
| BR-01 | 所有查询必须带 `user_id`，越权返回 403 |
| BR-02 | 所有删除为软删 |
| BR-03 | 资料必须属于某课程；章节为空表示未归类 |
| BR-04 | 题目必须属于某课程，章节可选；课程名/章节名写快照 |
| BR-05 | 题目与复习卡**同库同事务**创建 |
| BR-06 | 客观题必须先作答再看答案；主观/图片题可直接看答案 |
| BR-07 | 判分在**服务端**，前端不可提交"我答对了" |
| BR-08 | 判分 → rating：`1.0 → 2`、`0 < score < 1 → 1`、`0 → 0` |
| BR-09 | 掌握判定：`interval_days >= 30` 或连续 3 次 rating=2 |
| BR-10 | 每日复习上限默认 50（10~200 可调） |
| BR-11 | 文件白名单：pdf/doc/docx/ppt/pptx/txt/md/png/jpg/webp；单文件 ≤ 200MB |
| BR-12 | **原件不可变**：转换、OCR 都不覆盖原文件；重新解析只替换派生数据 |
| BR-13 | 转换失败（加密/损坏/超时）→ `FAILED`，原件仍可下载预览（能转就转，转不了就直出原图） |
| BR-14 | 文本抽取为空或去空白后 < 20 字符 → 触发该页 OCR |
| BR-15 | OCR 并发 2、单页超时 30 秒、失败重试 2 次后标 `NONE`；不因单页失败中断整篇 |
| BR-16 | 单文件 OCR 页数上限 300 页，超出部分标 `NONE` |
| BR-17 | 未配置 OCR 密钥 → 跳过 OCR，全部标 `NONE`，功能降级但**不报错** |
| BR-18 | 全文检索只在本人的资料内进行；关键词长度 ≥ 2 |
| BR-19 | 组卷抽题不重复；试卷保存快照 |
| BR-20 | 列表分页默认 20，最大 100 |
| BR-21 | 时区 `Asia/Shanghai`；`due_date` 只比日期 |

**判分规则表（BR-07 展开）：**

| 题型 | 判分 | 说明 |
|---|---|---|
| 单选 | 答案键完全一致 → 1.0，否则 0 | 未作答记 0 |
| 判断 | 同上 | 布尔比较 |
| 多选 | 全对 1.0；**仅漏选** → 0.5（可配 0）；**含错选** → 0 | 借鉴定级考试给分 |
| 填空 | 归一化（去空格、忽略大小写、全半角）+ 多答案任一匹配 → 1.0 / 0 | 不做模糊匹配 |
| 主观 / 图片 | 不判分，自评 0/1/2 | 直接作为 rating |

## 6. 关键用例

### UC-01 传课件、解析、出题、复习（V1 主线）

- **主流程**：建课程 → 传一份 60 页 PPTX → 状态"转换中 → 抽取中" → 完成后打开预览 → 翻到第 12 页 → 划选一段文字 → "出题" → 选单选、填 4 个选项与答案 → 保存 → 今日复习出现该题 → 选错 → 判分 → 点"看原文"跳回第 12 页
- **验收**：60 页 PPTX 转换 + 抽取 ≤ 20 秒；题目详情显示"《第 3 章 树》第 12 页"

### UC-02 扫描版 PDF（V1 关键场景）

- **前置**：一份纯图片的 PDF，共 40 页
- **主流程**：上传 → 转换直通 → 逐页抽文字均为空 → 逐页 OCR（显示"OCR 12/40"）→ 完成，状态 `SUCCESS`，每页标注"识别文字" → 点第 5 页，右侧面板显示识别结果 → 在面板里选中一句 → 出题
- **异常**：某页 OCR 失败 → 该页标 `NONE`，整篇状态 `PARTIAL`，其余页不受影响；未配置密钥 → 整篇 `NONE`，提示"未启用 OCR"
- **验收**：40 页扫描件 ≤ 3 分钟处理完；第 5 页文字面板内容与原图肉眼一致（允许个别错字）

### UC-03 检索定位（V2）

- **主流程**：课程内搜"红黑树" → 命中 5 处，显示资料名 + 页码 + 高亮片段 → 点击跳到预览对应页
- **异常**：该页 `text_source = NONE` → 不参与检索，列表中灰显
- **验收**：搜索结果页码与预览实际页一致

### UC-04 客观题复习（V1）

- **主流程**：今日复习 → 题干与选项 → 选 A → 提交 → 服务端判分 → 对错与解析 → rating 自动确定 → 下一题
- **异常**：未选就提交 → 提示；重复提交 → 幂等键拦截
- **验收**：多选漏选得 0.5 分，rating=1，间隔按"模糊"计算

### UC-05 组卷自测（V2）

- **主流程**：选课程与题量 10 → 抽题 → 作答 → 交卷 → 客观题自动判、主观题自评 → 得分 → 10 张卡到期日更新
- **验收**：8 客观 + 2 主观，得分与结果页一致

## 7. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 普通接口 P95 < 500ms；今日队列 < 200ms |
| 转换 | 100 页 PPTX 转 PDF ≤ 30 秒；转换进程隔离子进程，失败不影响服务 |
| 抽取 | 100 页原生 PDF ≤ 15 秒 |
| OCR | 单页 ≤ 3 秒（并发 2）；40 页扫描件 ≤ 3 分钟；**不阻塞阅读**（先可看，文字后到） |
| 资源 | LibreOffice 容器约 400MB；OCR 为云调用，无本地模型 |
| 安全 | 密码 BCrypt；JWT 密钥外置；文件类型/大小双校验；对象 key 用 UUID；SQL 全参数绑定 |
| 隐私 | 启用 OCR 时页图会上传第三方；设置中提供总开关，默认开启并明确告知 |
| 可用性 | `docker compose up` 一键启动 |
| 数据量 | 用户 ≤ 100；课程 ≤ 50/人；资料 ≤ 500/人；题目 ≤ 5000/人；单文件页 ≤ 500 |

## 9. 风险与取舍

| 风险 | 说明 | 对策 |
|---|---|---|
| 扫描件 OCR 质量 | 手写、公式、复杂版式识别差 | 只承诺"印刷体正文"；错字允许，答不上就看图；报告写清局限 |
| OCR 费用 | 按次计费，扫描件页数多 | 只对无文本层的页调用；单文件 ≤ 300 页；免费额度内演示 |
| 隐私/版权 | 页图要发给第三方 | 提供总开关；报告注明；只处理用户自己上传的资料 |
| LibreOffice 中文字体 | 容器缺中文字体会导致转出方块 | 镜像内装 `fonts-noto-cjk`，否则整条管线废掉 |
| 页码口径 | DOCX 转 PDF 后页码与 Word 不一致 | 统一以 PDF 页码为准，界面注明 |
| 转换失败 | 加密 PDF、损坏文件、超大文件 | 状态 `FAILED`，原件仍可下载；不阻塞其他资料 |
| 解析占资源 | 转换是重 CPU 操作 | 独立线程池 + 子进程隔离 + 超时熔断 |
| 范围膨胀 | 52 条功能 | 严格 V1→V2→V3 |

## 10. 待确认（1 条）

1. **OCR 用哪家云？** 百度 / 腾讯 / 阿里，接口形态接近（图片 base64 → 文本 + 坐标），建议先接一家 + 抽象 `OcrProvider` 接口，和 ASR 的做法保持一致。默认推荐**百度通用文字识别**（中文文档场景成熟、有免费额度）。
