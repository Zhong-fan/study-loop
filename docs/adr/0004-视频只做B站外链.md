# 0004. 视频只做 B 站外链，不下载不转码

- 状态：**Superseded by [0006](0006-视频解析用ytdlp加本地whisper.md)**
- 日期：2026-11-07
- 决策者：全员

> 本条已被 ADR-0006 取代。需求澄清后明确"视频的核心价值是解析成可检索的文本"，只做外链播放无法支撑该目标；且来源不能限定 B 站。保留本文以记录取舍过程。

## 背景

需求里"资料"包含网课视频，参考项目 BiliNote（7.7k star）的做法是"贴链接 → 抓元数据 → 站内看 → 记笔记"。需要决定视频到底怎么存、怎么播。

实测（2026-11-07）：`GET https://api.bilibili.com/x/web-interface/view?bvid=xxx` 无登录即返回 `code=0`，可取到标题、封面、UP 主、时长、分 P 列表、字幕列表。说明元数据抓取可行。

## 决策

1. **只存 B 站链接 + 抓取到的元数据**，视频文件本身不落地。
2. 播放用 B 站官方 iframe 播放器嵌入。
3. 观看进度与笔记时间点**手动标记**，不做自动识别。
4. 抓取失败时允许用户手填标题，不阻塞保存。

## 后果

**正面**

- 零存储成本、零带宽压力，MinIO 只放文档
- 没有版权风险（不下载、不转码、不二次分发）
- 元数据抓取是纯 HTTP 调用，代码量极小

**负面**

- 拿不到播放进度：iframe 跨域，父页面读不到播放器状态
- 依赖第三方接口，随时可能加签名/风控
- **内容不可检索**：一小时视频仍然是"黑盒"，无法搜索、无法按知识点定位

## 备选方案

| 方案 | 为什么不选 |
|---|---|
| 本地上传视频到 MinIO | 存储与带宽成本高，版权风险 |
| 爬取并下载 B 站视频 | 违反平台协议 |
| 只存链接，不做站内播放 | 体验割裂 |
