# 0005. 复习算法采用 SM-2 简化版

- 状态：Accepted
- 日期：2026-11-07
- 决策者：全员

## 背景

错题复习需要一个排期算法：今天评完，下一次什么时候再出现。可选方案从"固定间隔表"到"FSRS"跨度很大。

约束：**必须能在答辩时讲清楚，且能现场改一个参数演示效果**。

## 决策

采用 **SM-2 的简化版**：把原版 0~5 六档评分压缩成三档（忘记 / 模糊 / 记住），保留难度系数 EF、间隔、连续次数三个状态。

```
EF' = clamp(EF + (0.1 - (5-q) * (0.08 + (5-q) * 0.02)), 1.3, 2.8)

q < 3  → reps = 0, lapses++, interval = 1, 状态 = RELEARNING
q >= 3 → reps == 0 ? interval = 1
         reps == 1 ? interval = 6
         否则       interval = round(interval * EF')
         reps++, 状态 = REVIEW

due_date = 今天 + interval  （上限 365 天）
```

初始值 `EF = 2.5`、`interval = 0`、`reps = 0`、`due_date = 录入当天`。

## 后果

**正面**

- 三个状态变量、三十行代码，任何人都能追问到底
- 有论文出处（SuperMemo 2），不是自己编的
- 参数可解释：为什么明天复习、为什么变成 6 天，都能当场算给老师看
- 数据量小，一张 `review_card` 就能承载

**负面**

- 精度不如 FSRS：SM-2 假设"同一张卡的遗忘曲线稳定"，不区分题目难度与个人记忆差异
- 三档评分损失信息：原版 6 档能区分"勉强想起"和"很轻松"
- 没有考虑"同一知识点下多道题"的关联，只按单卡排期

**可以讲出来的改进方向**（V3 加分项）：把 `rating` 从三档恢复为四档、按章节聚合出"知识点掌握度"反过来调整间隔。

## 备选方案

| 方案 | 为什么不选 |
|---|---|
| FSRS | 17 个参数需大量复习历史拟合，冷启动无效；答辩无法解释公式来源 |
| 固定艾宾浩斯表（1/2/4/7/15 天） | 太死板，答错和答对走同一条曲线，看不出算法存在 |
| Leitner 盒子（5 个盒子轮转） | 简单但间隔固定，无法体现"越熟间隔越长" |
| 自己拍脑袋的加权公式 | 无法引用，最容易被追问到崩 |
