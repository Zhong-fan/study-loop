# 需求确认清单

> 只记录**已确认的**和**还需要你拍板的**。不写技术方案、不写表结构、不写排期。

---

## 一、已确认

| # | 结论 |
|---|---|
| 1 | 使用者只有学生本人，不做教师端、不做班级 |
| 2 | 视频（网课、录屏）先放一边，重点做 PPT、PDF 这类课件 |
| 3 | 扫描版 PDF、图片型 PPT 也要能处理，不能只支持有文字层的文件 |
| 4 | 选择题必须能由程序判分，不能靠用户自评 |
| 5 | 组卷自测、复习提醒都要 |
| 6 | 时间不紧张，不按周排期 |

---

## 二、我理解的使用场景（请确认是否对）

1. 我把课件（PPT / PDF）传到系统里。
2. 我在网页里翻着看，不用下载。
3. 看到重点或做错的地方，直接把它变成一道题。
4. 系统每天告诉我"今天该复习哪几道"。
5. 复习时选择题自动判分，我只看解析。
6. 我能看到自己哪一章最弱。

---

## 三、功能候选（待你勾选 / 删减）

**资料**

- 上传课件（PDF / PPT / Word / 图片）
- 网页内阅读：翻页、缩放、选中文字
- 扫描件也能读：图片页识别成文字
- 按课程 / 章节归类
- 搜索资料里的文字
- 收藏、最近打开

**题目**

- 从资料里划选一句话直接出题
- 手动录入题目（含图片）
- 题型：单选 / 多选 / 判断 / 填空 / 主观 / 图片
- 题目归类：课程、章节、标签、难度
- 选择题程序判分

**复习**

- 每天给一个"今日待复习"列表
- 复习时先作答、再看答案和解析
- 记录每次复习结果
- 组卷自测（抽若干题做一套）
- 复习提醒

**统计**

- 待复习数量、今日完成、掌握率
- 哪一章错得最多
- 各题型正确率

## 四、待确认的问题

1. **多账号还是单账号？** 是自己一个人用，还是要能注册多个账号、各自数据隔离？
2. **课程和章节是两级树，还是只要"文件夹"式的分组？**
3. **出题主要靠哪种方式？** 划选出题为主，还是手动录入为主，还是两者都要？
4. **自动判分覆盖到哪些题型？** 只有单选、多选，还是判断题、填空题也要？
5. **组卷的题从哪来？** 只从错题里抽，还是所有题都能抽？
6. **提醒要什么形式？** 首页红点、今日待复习列表，还是要发邮件 / 浏览器通知？
7. **除了题目，需不需要"笔记"？** 比如在某一页、某一段上写备注。
8. **需不需要导出？** 比如把错题导出成 PDF 或 Excel。
